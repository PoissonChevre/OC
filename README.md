# OpenClassrooms : Administrateur systèmes, réseaux et sécurité

[Parcours sur OpenClassrooms](https://openclassrooms.com/fr/paths/734-administrateur-systemes-reseaux-et-securite) · **Terminé en mai 2024** · Titre RNCP niveau 6 (Bac+3/4), reconnu par l'État

## À propos

Un parcours professionnalisant de 13 projets concrets, qui couvrent les domaines clés d'un système d'information : réseau, administration Linux et Windows, sécurité, supervision, sauvegarde, automatisation et cloud.

Chaque projet part d'un cas d'entreprise, avec un cahier des charges et des livrables présentés en soutenance.

## Technologies utilisées

| Domaine | Outils |
|---|---|
| Administration système | Linux (Debian, Ubuntu), Windows Server, Active Directory |
| Support IT | ITIL, GLPI |
| Réseau et sécurité | Cisco, VPN, pare-feu, Fail2ban |
| Services | Apache, MySQL, Bind9, SFTP, Nagios, rsync |
| Virtualisation et cloud | VirtualBox, VMware, AWS |
| Automatisation | Ansible, Bash, Python, PowerShell |
